# Retail Sales Clustering and Classification

An end-to-end Machine Learning project that analyzes retail sales data, identifies customer or sales patterns through clustering, and uses supervised classification models to predict cluster assignments.

The project combines SQL data integration, data preprocessing, K-Means clustering, DBSCAN, classification, model evaluation, and a Streamlit web application.

## Project Overview

The goal is to analyze retail sales data and discover meaningful patterns using unsupervised learning. The clusters generated by K-Means are then used as target labels to train classification models.

The project includes:

- Data integration using SQLite and SQL JOIN operations.
- Data cleaning and preprocessing.
- Missing value treatment.
- Categorical encoding.
- Numerical feature scaling.
- K-Means clustering.
- DBSCAN clustering.
- PCA-based cluster visualization.
- Classification using Logistic Regression and Random Forest.
- Hyperparameter tuning using GridSearchCV.
- Model evaluation.
- Model saving and loading with Joblib.
- Input validation.
- Interactive Streamlit application.

## Machine Learning Workflow

### 1. Data Integration

The project loads three related Excel datasets:

- Sales
- Salespeople
- Products

It stores them in SQLite tables and combines them using SQL JOIN operations to create a master dataset.

### 2. Data Preprocessing

The preprocessing stage includes:

- Handling missing numerical values using median imputation.
- Handling missing categorical values using mode imputation.
- Removing duplicate records.
- Removing unnecessary and constant columns.
- Handling high-cardinality categorical features.
- Encoding categorical variables.
- Standardizing numerical features.

### 3. Clustering

Two clustering algorithms are implemented.

K-Means:
- Tests multiple values of K.
- Uses the Elbow Method and Silhouette Score.
- Selects the best-performing cluster configuration.
- Generates cluster labels.

DBSCAN:
- Tests different epsilon and minimum sample values.
- Identifies dense regions and noise points.
- Evaluates clustering quality using the Silhouette Score where valid.

PCA is used to visualize cluster distributions in two dimensions.

### 4. Classification

The K-Means cluster labels become the target variable for supervised classification.

The project trains:

- Logistic Regression
- Random Forest Classifier

GridSearchCV is used to tune model hyperparameters.

### 5. Model Evaluation

Classification models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Important: These classification metrics measure how well the classifiers reproduce K-Means cluster assignments. They do not establish that the clusters represent correct real-world business categories. K-Means itself is evaluated using clustering metrics such as Silhouette Score and inertia.

### 6. Model Saving

The trained preprocessing and prediction components are saved using Joblib.

The saved model bundle contains the preprocessing pipeline, K-Means model, classifier, feature information, and selected model configuration.

The Streamlit application loads this saved bundle to make predictions.

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Retail-Sales-ML
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Notebook

Open the Jupyter Notebook:

```bash
jupyter notebook
```

Run `Retail_Sales_ML_Workflow_Improved.ipynb` from beginning to end.

Make sure the three Excel datasets are available in the expected location.

The notebook trains the models and saves the Joblib pipeline:

```text
retail_sales_ml_pipeline.joblib
```

Keep this file in the same directory as `app.py`.

## Running the Streamlit Application

Start the application:

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.

The application supports:

- Individual predictions through a user input form.
- Batch predictions through CSV upload.
- K-Means cluster assignment.
- Classification predictions.
- Prediction confidence when supported by the selected classifier.
- Input schema information.

## Input Requirements

For batch predictions, upload a CSV file containing the same feature columns used during model training.

The uploaded data must:

- Include all required model features.
- Use compatible numerical values.
- Use categorical values consistent with the training data.
- Exclude unnecessary columns that were removed during preprocessing.

## Limitations

- K-Means cluster labels are generated without ground-truth labels.
- Classification performance reflects agreement with K-Means assignments.
- DBSCAN may classify some observations as noise.
- Predictions depend on the quality and structure of the training data.
- The application requires the trained Joblib file.
